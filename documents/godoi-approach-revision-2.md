Dear Mr Godoi,

I am writing to introduce a project that may be of interest to UNESCO's work on multilingualism in the digital era.

AllSpeak is an open-source programming tool that allows code to be written, read, and understood in any human language for which it has been implemented. Where conventional programming languages require English syntax, AllSpeak presents the same underlying logic in whichever language the programmer chooses from those available. It is currently operational in four languages - English, French, German, and Italian - and its architecture is designed to be extended to any language, including those using non-Latin scripts.

The project addresses a structural gap. Every mainstream programming language uses English keywords. This means that computational literacy - increasingly recognised as a foundational skill - is strongly biased towards those who can work comfortably in English. The 6.5 billion people worldwide who are not English speakers are, in effect, barred from understanding the code that increasingly shapes their lives.

I was struck by UNESCO's Global Roadmap on Multilingualism in the Digital Era and its call for industry to "design inclusive Language Technologies". AllSpeak does this at the syntactic level: the code itself is in the learner's language, not merely the documentation around it. A companion white paper (available on Zenodo: https://doi.org/10.5281/zenodo.22018537) describes the architecture, the methodology for adding new languages, and the real-world applications already running on it. A fifteen-minute narrated demonstration video (https://youtu.be/BSvh4MPEzV4) shows AllSpeak building and running a graphical application from scratch.

A steadily increasing proportion of the world's code is now being written by AI, and that code must still be read, checked, and maintained by humans. AllSpeak is designed for this division of labour. AI has no trouble coding with AllSpeak when instructed to do so, and tends to make fewer mistakes in its small, constrained grammar than when writing in mainstream programming languages. The result is scripts that are far easier to read and understand, especially when they are written in the reader's native language.

I am an individual developer, not an organisation. I am writing not with a funding request but to ask whether AllSpeak might be of interest to UNESCO as a case study, a reference implementation, or a tool to share with language communities working towards digital participation. I would be glad to arrange a demonstration and to share the white paper and supporting materials.
