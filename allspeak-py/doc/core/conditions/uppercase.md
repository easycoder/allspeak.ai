# uppercase

## Syntax:
`{value} is [not] uppercase`

## Examples:
``if Code is uppercase log `all caps` ``

## Description:
Tests if the value is written entirely in upper case. The value must contain at least one cased letter for the test to pass — `ABC-123` is upper case, while `123` on its own is not. The two-word spelling `is upper case` means the same thing. The inclusion of `[not]` negates the test.
