# lowercase

## Syntax:
`{value} is [not] lowercase`

## Examples:
``if Code is not lowercase stop``

## Description:
Tests if the value is written entirely in lower case. The value must contain at least one cased letter for the test to pass, so an empty value, a number or `123abc`-style text with no lower-case letters does not count as lower case. The two-word spelling `is lower case` means the same thing. The inclusion of `[not]` negates the test.
